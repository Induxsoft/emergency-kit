
# Guía de configuración general

Esta guía tiene como objetivo orientar a los usuarios en la configuración de ubicaciones dentro de sus catálogos, en caso de que así lo requieran.

La asignación de ubicaciones permite diferenciar las distintas sucursales y los datos correspondientes a cada una.

EJEMPLO: 
Si la Sucursal 1 y la Sucursal 2 utilizan la misma base de datos (BD01), y cada una registra sus propios catálogos, al asociar cada registro con su ubicación correspondiente, será posible identificar fácilmente a qué sucursal pertenece cada dato.

| Centro de consumo | Ubicación |
|-------------------|-----------|
|CC001              |Sucursal 1 |
|CC002              |Sucursal 2 |

### Catálogos que pueden configurarse con ubicación.
- Centro de consumo.
- Centro de producción.
- Cajas.
- Cajeros.
- Agentes.
- Repartidores.
- Almacenes.
- Control de folios(block de documentos).

### Agregar ubicaciones
1. Ingrese al sistema V12.
2. Busque y seleccione la opción "Agregar ubicación" en la barra de acceso rápido.

## Configurar catálogos con ubicación
1. Acceda al catálogo que desea configurar.
2. Haga clic en Agregar o Editar.
3. Seleccione la ubicación correspondiente.
4. Guarde los cambios.
5. Repita este proceso para cada registro dentro del catálogo.

```
Nota: Este procedimiento debe realizarse para cada uno de los catálogos mencionados.
```
